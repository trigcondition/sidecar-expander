Sidecar stands on open-source work. Thank you to everyone behind these projects.

| Project | Licence | Used for |
|---|---|---|
| [Circle](https://github.com/rsta2/circle) | GPLv3 | the Pi's bare-metal environment: USB, networking, SD card, multicore |
| [LVGL](https://lvgl.io) | MIT | the Pi display's interface |
| [elekloader](https://github.com/irpina/elekloader) | GPL-2.0-or-later | the code space for the Rytm mods, and the patcher's firmware codec (from digikit) |
| [Mutable Instruments Plaits and Rings](https://github.com/pichenettes/eurorack) | MIT | the PLAITS and 6-OP FM machines, and the RINGS send effect |
| [Cloud Seed](https://github.com/GhostNoteAudio/CloudSeedCore) | MIT | the CLOUDSEED send effect |
| [DaisySP](https://github.com/electro-smith/DaisySP) | MIT | the DAISYSP and DSP SAMPLE resonators |
| [AMY](https://github.com/shorepine/amy) | MIT | the Juno-106 model our JUNO voice follows |
| [digidrum](https://github.com/soejrd/digidrum) | MIT | the DIGIDRUM machines |
| [mdkit](https://github.com/soejrd/mdkit) | CC0 1.0 | the MD user machine (used with the developer's agreement) |
| Teensyduino, USBHost_t36, SdFat, littlefs | MIT, LGPL-2.1, BSD | the Teensy build |
| FatFs | BSD-style | the Pi's file system |
| Circle addon/wlan (from Plan 9) and wpa_supplicant (hostap) | GPL-2.0; BSD-3-Clause | the Pi's Wi-Fi (off in the package) |
| [Astro Starlight](https://starlight.astro.build) | MIT | this site |
| [Archivo Black](https://github.com/Omnibus-Type/ArchivoBlack) | OFL-1.1 | the wordmark |

The authors and the full notices are in [THIRD_PARTY_LICENSES](https://github.com/trigcondition/sidecar-expander/blob/main/THIRD_PARTY_LICENSES).

Our own voices, effects and machines (the JUNO voice, CHORUS, COMB, CRUSH, RINGMOD, STUTTER, the starter machines) are original code.
