<Diagram />

<p class="sc-lede">A small computer on the Rytm's USB port, <b>Sidecar Mini</b> on a Teensy 4.1 or the full <b>Sidecar</b> on a Raspberry Pi 4B or Pi 5, plus a set of mods to the Rytm's OS 1.73. The Sidecar's voices come back on the Rytm's own tracks, through its analog filters and amps, and its effects sit beside the Rytm's delay and reverb.</p>

<div id="features" class="sc-features">

<Feature kicker="Voices" title="Digital machines on every track" href="/sidecar-expander/using/machines/" shots={[
  { src: plaits, alt: 'A PLAITS voice page on the Rytm', pixel: true },
  { src: juno, alt: 'The JUNO page with its envelope', pixel: true },
  { src: fm, alt: 'The 6-OP FM page with its algorithm', pixel: true },
  { src: grain, alt: 'The GRAIN view of DSP SAMPLE', pixel: true },
]}>
  <p>Pick PLAITS, JUNO, 6-OP FM, DAISYSP, DIGIDRUM or DSP SAMPLE in a track's machine list, like any Rytm machine. DSP SAMPLE plays from the Sidecar's card, with slices, loops and a granular mode. Five user slots load machine plugins: six starter machines come with the release.</p>
</Feature>

<Feature flip kicker="Send effects" title="Two send effects next to the Rytm's own" href="/sidecar-expander/using/send-effects/" shots={[
  { src: halo, alt: 'SEND FX 1 set to HALO with DCY, MOD, TONE, SHIM', pixel: true },
  { src: rings, alt: 'SEND FX 1 set to RINGS', pixel: true },
  { src: stutter, alt: 'SEND FX 2 set to STUTTER', pixel: true },
]}>
  <p>Every track gets two more sends. <b>HALO</b>, a lush plate with FREEZE and SHIMMER, runs on both Sidecars with CHORUS, COMB, CRUSH and RINGMOD; the Pi adds RINGS, CLOUD SEED and STUTTER. Each effect's knobs carry their own names on the Rytm's pages, and PRE / POST decides whether the return goes through the Rytm's analog distortion and compressor.</p>
</Feature>

<Feature kicker="On the Rytm's screen" title="Pages the Sidecar draws for you" href="/sidecar-expander/using/rytm-side/#the-remote-ui" shots={[
  { src: statusP, alt: 'The SIDECAR status page', pixel: true },
  { src: scope, alt: 'SCOPE with twelve meters', pixel: true },
  { src: lfoDesign, alt: 'The LFO design view with 16 steps', pixel: true },
  { src: connect, alt: 'The connect screen', pixel: true },
]}>
  <p>Hold TRK and press YES: status pages, a scope with meters, the recorder and an LFO designer, in the Rytm's own font. On a track with a Sidecar machine, the Rytm's own SRC page shows the machine's page with its graphics while every knob stays the Rytm's. The Rytm keeps playing underneath: PLAY, STOP, the pads and mutes still work. New pages arrive with a Sidecar update, without reflashing the Rytm. </p>
</Feature>

<Feature flip kicker="Modulation" title="LFOs, with your own wave" href="/sidecar-expander/using/lfo/" shots={[
  { src: piLfo, alt: 'The web page LFO tab' },
]}>
  <p>Eight LFOs on the Pi, four on the Mini, on any parameter of a Sidecar voice or effect, saved per kit. Free or synced to the Rytm, retriggered by a trig or PLAY, and a DESIGN wave of 16 steps you draw on the Rytm (TRK + LFO) or in the browser. <span class="sc-test">in testing</span></p>
</Feature>

<Feature kicker="Recording" title="Record every track, play it back" href="/sidecar-expander/using/recorder/" shots={[
  { src: rec, alt: 'The REC page, armed', pixel: true },
  { src: play, alt: 'The REC page playing a channel of a take', pixel: true },
  { src: piRecord, alt: 'The web page Record tab with takes' },
]}>
  <p>Record the Rytm's tracks, the Sidecar's voices and the effect returns to the SD card, one aligned WAV per source, from the Rytm's REC page or armed to PLAY. On the Pi, play a take's channel back into the Rytm's mix. The Rytm's own delay and reverb can be recorded as their own channels. Sidecar Mini records stereo to its card, from the same REC page.</p>
</Feature>

<Feature flip kicker="Computer audio" title="An audio interface for your DAW" href="/sidecar-expander/using/usb-audio-midi/" shots={[
  { src: piSound, alt: 'The web page Sound tab' },
  { src: miniUsb, alt: 'The Sidecar Mini console USB tab' },
]}>
  <p>With the Sidecar on the Rytm's USB port, its own USB port becomes a class-compliant audio and MIDI device for your computer: multi-channel on the Pi, stereo on the Mini. No driver needed.</p>
</Feature>

<Feature kicker="Web UI and plugins" title="Manage it from a browser" href="/sidecar-expander/using/web-ui/" shots={[
  { src: piMachines, alt: 'The web page User machines tab' },
]}>
  <p>The Pi serves its own page at <code>sidecar.local</code>; the Mini has a console in Chrome or Edge over USB. Install user machines, see the CPU and memory, fill the sample pool, browse and upload whole sample folders, set up Wi-Fi. Nothing leaves your network.</p>
</Feature>

<Feature flip kicker="Touchscreen" title="A screen of its own" href="/sidecar-expander/using/display/" shots={[
  { src: dispHome, alt: 'The display home screen' },
  { src: dispFx, alt: 'The display Send FX page' },
]}>
  <p>The Pi drives an 800x480 touch display: the tracks and their machines, the project's user slots, the send levels, the core loads and the recorder at a glance, with sound settings, screensaver and brightness by touch.</p>
</Feature>

<Feature kicker="Poly mode · 0.3 test line" title="A sequencer for poly tracks" href="/sidecar-expander/using/sequencer/" shots={[
  { src: seqMake, alt: 'The make prompt: MAKE LT A SIDECAR SEQ TRACK?', pixel: true },
  { src: seqHeld, alt: 'The SEQ page with a step held: its chord on a keyboard', pixel: true },
  { src: seqLock, alt: 'LOCK SRC: p-locks on seq steps', pixel: true },
  { src: touchSeq, alt: 'The touchscreen piano roll' },
]}>
  <p>TRK + TRIG makes a track a Sidecar seq track: chords and several notes per step, each with its own velocity, length and micro timing, up to 8 pages, p-locks on the Sidecar's parameters, step preview, edited on the Rytm's own trig keys and on the touchscreen's piano roll. The Rytm stays the master. <span class="sc-test">in testing</span></p>
</Feature>

<Feature flip kicker="Poly machines · 0.3 test line" title="MULTISAMPLE, WAVETABLE, GRANULAR" href="/sidecar-expander/using/poly-machines/" shots={[
  { src: msChord, alt: 'MULTISAMPLE with a chord on the Rytm', pixel: true },
  { src: wtPage, alt: 'WAVETABLE on the Rytm', pixel: true },
  { src: grTouch, alt: 'GRANULAR on the touchscreen' },
  { src: bankTouch, alt: 'Source bank C on the touchscreen' },
]}>
  <p>Three polyphonic machines with chords on four knobs: SFZ instruments streamed from the card, band-limited wavetables, and grains on samples or the Rytm's live audio. Their sources come in 8 banks of 128, chosen from a list on the Rytm's SRC page. <span class="sc-test">in testing</span></p>
</Feature>

<Feature kicker="Inserts, sampling, songs · 0.3 test line" title="Inserts, a sampler and a song recorder" href="/sidecar-expander/using/insert-fx/" shots={[
  { src: insTouch, alt: 'The INSERT FX page on the touchscreen' },
  { src: autoExt, alt: 'The AUTO page on the Rytm', pixel: true },
  { src: songTouch, alt: 'The song timeline on the touchscreen' },
  { src: recTouch, alt: 'The REC page on the touchscreen' },
]}>
  <p>Two <a href="/sidecar-expander/using/insert-fx/">insert slots</a> on every Sidecar voice and three FX buses; a <a href="/sidecar-expander/using/sampling/">sampler and auto-sampler</a> that turns a patch, a Rytm track or an external synth into a MULTISAMPLE instrument; a <a href="/sidecar-expander/using/song-recorder/">song recorder</a> that captures a whole performance and replays it; and a <a href="/sidecar-expander/using/touchscreen/">touchscreen</a> with two themes, at 800x480 or 1024x600. <span class="sc-test">in testing</span></p>
</Feature>
