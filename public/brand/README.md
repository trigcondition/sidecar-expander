# Sidecar logos

- `sidecar-mark.svg`: the S with its green bar, on a rounded dark square (the site's icon, larger).
- `sidecar-avatar-dark.svg`, `sidecar-avatar-light.svg`: for a profile picture; the mark stays inside the circle sites crop to.
- `sidecar-wordmark-white.svg`, `sidecar-wordmark-black.svg`: SIDECAR, drawn, no font needed.
- `sidecar-youtube-banner.svg`: 2560 x 1440, the wordmark inside YouTube's safe area.
- `sidecar-reddit-banner.svg`: 1920 x 384.

`png/` holds a rendering of each. Colours: `#0e0e0e`, `#ffffff`, green `#1fa64a`.
